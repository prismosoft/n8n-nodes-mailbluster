# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Run `npm ci`.
3. Make the change with tests where practical.
4. Run `npm run lint` and `npm test`.
5. Open a pull request describing the API behavior being changed and the MailBluster documentation used to verify it.

Do not commit API keys, subscriber data, generated `dist/` output, or local `.env` files.
